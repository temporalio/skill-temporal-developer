DNS Load Balancing (Concepts)

Use dns:/// at the start of the gRPC target to enable round-robin across resolved IPs.

Use dns:/// with publicClient hostPort as well.

For details on gRPC target URI schemes, see the gRPC naming doc: https://github.com/grpc/grpc/blob/master/doc/naming.md

See language-specific guidance at references/typescript/dns-load-balancing.md, references/dotnet/dns-load-balancing.md, and references/ruby/dns-load-balancing.md.
